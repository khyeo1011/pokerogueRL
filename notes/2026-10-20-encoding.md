# Fixed-size encoding: findings

2026-10-20, for issue #16. pokerogue v1.12.1.1 (`bdfbef6`), Node 24.19, Linux.

**Result:** `bridge/encoding.ts` turns every observation into `OBS_DIM = 2102` numbers and every action
into an index in `[0, N_ACTIONS = 272)`. `actionMask(legal)` allows exactly the legal actions that have a
slot, and `decodeAction(index, legal)` maps an index back to its action. `bridge/test/encoding.test.ts`
plays level-100 runs only through the mask, as MaskablePPO would.

## Layout

| Part | Width | Notes |
|---|---|---|
| Stage one-hot | 14 | every `StageObs` kind, including stages scripted until phase 4 |
| Stage block | 222 | shared: each stage writes from its start; widest is the reward screen (8 options + 14 shop) |
| Run | 168 | wave, biome, money, balls, 32 modifier slots |
| Party | 6 × 192 | by party slot, the same order the actions use |
| Battle | 546 | weather, terrain, 8 arena tags, trainer tray, 16 enemy modifiers, 2 enemies by field slot |

Action blocks are per action kind (`ACTION_BLOCKS`), so the space is the same at every stage. `switch` is
shared by `command`, `switch` and `checkSwitch`; the stage one-hot tells them apart. `itemTarget` has three
blocks: plain, with a move (PP items, Memory Mushroom), with a second Pokémon (DNA Splicers).

ID slots hold `id + 1`, with 0 for none or unknown, to be embedded per vocabulary by the network (#17).
Unrevealed enemy moves and abilities are a known flag of 0 next to an ID of 0.

## Caps

Rewards 8, shop 14 (the whole row), Memory Mushroom moves 16, encounter options 8, encounter sub-menu
entries 16, held items 12, run modifiers 32, enemy modifiers 16, arena tags 8. A legal action past a cap
has no slot and is left out of the mask; `actionMask` throws if that leaves nothing legal.

## Gotchas

- **`rerollCost` is -1** on a reward screen with no options left (only the shop). It is encoded as a flag
  plus the cost, not as a log of a negative number.
- **`MysteryEncounterTier` values are spawn weights** (66, 40, 19, 3, 0), not positions; the one-hot uses
  their order.
- **Strings are not encoded.** Encounter option labels and tooltips and sub-menu labels are text; the
  vector has the encounter type, the option index, and the disabled and highlighted flags.

## Coverage

Three runs (Mewtwo, Rayquaza, Groudon at level 100, random unmasked indices) reached waves 35 and 64 and
raised 10 of the 14 stage kinds: not `biome`, `revive`, `meSubOption` or `checkSwitch` (the harness plays
in Set mode). The hand-built tests encode all 14. The same seed gave the same vectors twice.
